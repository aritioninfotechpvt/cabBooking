# cabBooking

RideFlow is an Ola/Uber-style mobility platform frontend.

## Projects

- `rideflow-demo/` — React + Vite professional Admin frontend.
- `rideflow-flutter-demo/` — Flutter Customer, Driver and Vendor/Fleet frontend demos.

## Run React Admin

```bash
cd rideflow-demo
npm install
npm run dev
```

## Run Flutter apps

```bash
cd rideflow-flutter-demo
flutter pub get
flutter run -t lib/main_customer.dart
```

Use `main_driver.dart` or `main_vendor.dart` for the other Flutter views.
